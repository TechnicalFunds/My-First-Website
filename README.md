# My-First-Website

## Accessibility and visual design

- I adjusted the text and background color combinations flagged by WAVE and checked them against WCAG AA contrast requirements with WebAIM Contrast Checker.
- Each contact-form control has an explicit label, required-field guidance, and an inline error message announced through its associated description when invalid.
- The form groups related contact fields with a `fieldset` and `legend`.
- **Proximity:** I group related content inside individual panels and keep each panel's heading, text, and links close together.
- **Similarity:** I repeat the same soft gray-green panels, coral top accents, navy text, and typography across all three pages to create a consistent visual system.
